# ویلرو — مواد تبلیغاتی

هر چیزی که برای جذب راننده و بعد مسافر لازم است: پوستر ایستگاه، پست
فیس‌بوک و واتساپ، متن‌های آمادهٔ کپی، طرح لانچ، و نسخه‌ای از متن‌های
فروشگاه‌های اپ.

---

## ⚠ پیش از چاپ یا خپرول

۱. **شمارهٔ تماس: برداشته شد (۲۰۲۶-۰۹-۲۱).** به انتخاب شما، خطِ «تماس و
   راهنمایی» از همهٔ پوسترها و از متن‌ها پاک شد؛ پایینِ پوستر فقط «یک محصول
   لینومیک» می‌ماند. اگر روزی شمارهٔ واقعی خواستید، یک `<div class="phone">`
   در بخش `class="foot"` پوستر بگذارید و `05-assets/render.sh` را اجرا کنید.

۲. **متن پشتو را یک پشتو‌زبان بخواند.** پوستر و پست پشتو را من نوشته‌ام و
   پشتو زبان مادری من نیست. یک غلط روی دیوار ایستگاه، اعتبار را پیش از
   شروع خراب می‌کند.

> پیشنهاد **«۱۰ سفر اول بدون کمیسیون»** تأیید شده (۲۰۲۶-۰۹-۲۰) و عمداً روی
> پوسترها و پست‌ها هست.

## نکته دربارهٔ لینک و QR

- **iOS زنده است.** هر دو اپ روی App Store منتشر شده‌اند (لینک‌ها در
  `01-plan/links.md`). پوسترِ راننده‌ی **App Store** —
  `02-posters/poster-driver-appstore-*` — QRش (`05-assets/qr-ios-driver.svg`)
  به صفحهٔ عمومیِ App Store می‌رود و **همین حالا کار می‌کند**. برای iOS همین
  را چاپ کنید.
- **اندروید هنوز آزمایش بسته است.** پوسترهای معمولیِ راننده/مسافر
  (`poster-driver-fa/ps`, `poster-passenger-fa`) QRشان به لینکِ **آزمایش
  گوگل‌پلی** می‌رود. تا وقتی در Play Console بخش Testers را از Google Groups
  به **Email list** نبرید (یا راننده‌ها را عضو گروپ نکنید)، آن QR برای
  کسی که تستر نیست کار نمی‌کند.

## عکس پروفایل حساب‌های اجتماعی

- `03-social/profile-velro.png` — همان نشان اپ (V که جاده است) روی سبز
  برند. **همین یک فایل** را در پروفایل فیس‌بوک، اینستاگرام، واتساپ، ایکس،
  یوتیوب و تلگرام بگذارید؛ هر کدام خودشان به اندازهٔ خودش کوچکش می‌کنند.
  چون این‌ها پروفایل را دایره‌ای می‌بُرند، نشان وسط قرار گرفته و بریده
  نمی‌شود. عکس پروفایل همان نشانی است که روی صفحهٔ گوشی هم هست.
- `03-social/profile-velro-driver.png` — همان نشان روی زمینهٔ تیرهٔ راننده،
  اگر برای راننده‌ها حساب جدا باز کردید.
- هر دو **۲۰۴۸×۲۰۴۸**‌اند و از `render.sh` ساخته می‌شوند، مثل بقیه.
- `05-assets/mark.svg` نشان تنها (سبز، پس‌زمینهٔ شفاف) برای زمینهٔ روشن —
  سربرگ، وب‌سایت، جاهایی که سبزِ پُر نمی‌خواهید.

## کاور (تصویر سرِ پروفایل)

هر پلتفرم اندازهٔ خودش را می‌خواهد و لبه‌ها را جور دیگری می‌بُرد، پس هر
کاور با **اندازهٔ دقیق همان پلتفرم** ساخته می‌شود. متن و نشان همه در «ناحیهٔ
امن» هر پلتفرم می‌مانند و بریده نمی‌شوند.

| فایل | برای | اندازه |
|---|---|---|
| `03-social/cover-fb.png` | کاور صفحهٔ فیس‌بوک | ۱۶۴۰×۶۲۴ |
| `03-social/cover-x.png` | هدر ایکس (توییتر) | ۱۵۰۰×۵۰۰ |
| `03-social/cover-youtube.png` | بنر کانال یوتیوب | ۲۵۶۰×۱۴۴۰ |

- بنر یوتیوب روی تلویزیون کامل دیده می‌شود ولی روی موبایل فقط وسطش
  (۱۵۴۶×۴۲۳)؛ برای همین همه‌چیز وسط جمع شده. آزمایش شد و داخل ناحیهٔ امن است.
- کاور فیس‌بوک روی موبایل از دو طرف کمی بریده می‌شود؛ متن به‌قدری وسط است
  که چیزی از دست نمی‌رود.
- اینستاگرام و واتساپ کاور ندارند؛ فقط عکس پروفایل.

## آگهی «به‌زودی» (تیزر)

سه اندازه که یک کمپین آگهی واقعاً لازم دارد — همه با همان نشان و سبز برند:

| فایل | برای | اندازه |
|---|---|---|
| `03-social/ad-comingsoon-square.png` | فید فیس‌بوک و اینستاگرام | ۱۰۸۰×۱۰۸۰ |
| `03-social/ad-comingsoon-story.png` | استوری و ریل (تمام‌صفحه) | ۱۰۸۰×۱۹۲۰ |
| `03-social/ad-comingsoon-wide.png` | آگهی افقی و لینک | ۱۲۰۰×۶۳۰ |

نسخهٔ **پښتو** هر سه با نام `ad-comingsoon-ps-square/story/wide` هست — همان
طرح، متنِ «ډېر ژر». (پسوند اندازه آخرِ نام است تا `render.sh` بگیردش.)

> ⚠ متن پښتو را من نوشته‌ام و پښتو زبان مادری‌ام نیست. پیش از خپرول یک
> پښتو‌زبان بخواند — به‌ویژه «کرایه او څوکۍ، تر حرکته مخکې معلومې».

- متن عمداً «به‌زودی» است، نه «همین حالا نصب کن» — تیزر است. این با ترتیب
  لانچ می‌خواند: تا وقتی راننده‌ها روی یک محور فعال نشده‌اند، مسافر را به
  اپِ خالی نمی‌فرستیم؛ ولی می‌شود از حالا نامِ ویلرو را در ذهن‌ها نشاند.
- استوری وسط‌چین است تا زیر دکمه‌های بالا و پایین اینستاگرام نرود.
- اگر خواستید تیزر «نصب کن» شود (وقتی راننده‌ها آماده شدند)، در همین
  فایل‌ها `به‌زودی` را به یک خط دعوت و لینک اپ عوض کنید و `render.sh`.

## ویدیو (انیمیشن)

ویدیوها حالا با پروژهٔ **Remotion** ساخته می‌شوند، در `~/Velro/motion/`
(در همین ریپو: `motion/`). صحنه‌ها: StoryFilm، GhorbandDrive، AcceptRide،
RequestRide، RouteMap، SeatFill، LogoReveal، StatsCounter، DayToNight،
NowOnAppStore و … — هرکدام دری و پښتو.

```bash
cd ~/Velro/motion && npm run studio     # پیش‌نمایش زنده
cd ~/Velro/motion && npx remotion render <id> out/<id>.mp4 --codec=h264 --crf=18
```

- راهنمای کامل: `motion/README.md`.
- `06-video/exports/` فقط نسخهٔ نهاییِ mp4هاست برای آپلود (در گیت نیست).
- `06-video/archive/` نسخهٔ قدیمیِ canvas است که با Remotion جایگزین شد.

## چاپ پوستر

- هر پوستر یک `.png` دارد با اندازهٔ **۲۴۸۰×۳۵۰۸** — یعنی A4 با ۳۰۰dpi،
  همان چیزی که چاپخانه می‌خواهد. همین فایل را بدهید.
- کنار هرکدام یک `_bw.png` هست: نسخهٔ سیاه‌وسفید، برای دکان فوتوکاپی.
  رنگی را که فوتوکاپی سیاه‌وسفید کنند، گِل‌آلود در می‌آید؛ این نسخه نه.
- کد QR هر پوستر آزمایش شده و خوانده می‌شود — حتی نسخهٔ سیاه‌وسفید.

## وقتی چیزی را تغییر دادید

فایل‌های `.html` اصل کار‌اند؛ `.png` فقط خروجی است. بعد از هر تغییر:

```bash
~/Desktop/Marketing/Velro/05-assets/render.sh
```

اگر لینکی عوض شد، اول `05-assets/make-qr.mjs` را اصلاح کنید و اجرا کنید:

```bash
node ~/Desktop/Marketing/Velro/05-assets/make-qr.mjs
```

## این پوشه در دو جا هست

- `~/Desktop/Marketing/Velro/` — **جایی که کار می‌کنید.** تصویرهای PNG هم
  همین‌جا ساخته می‌شوند.
- `~/Velro/marketing/` — **جایی که ذخیره می‌شود** و با GitHub می‌رود.
  فقط فایل‌های منبع (HTML، CSS، متن‌ها، QR، اسکریپت‌ها و فونت). PNGها
  ذخیره نمی‌شوند چون `render.sh` در دو ثانیه دوباره می‌سازدشان.

بعد از هر تغییر روی Desktop، این را بزنید تا در گیت هم ذخیره شود:

```bash
~/Velro/marketing/sync-from-desktop.sh
cd ~/Velro && git add marketing && git commit -m "marketing: ..." && git push
```
